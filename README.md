# 🎓 ERP Based Student Management System
## 📖 About

ERP Based Student Management System is a full-stack web application developed to simplify and digitalize academic administration. The system enables educational institutions to efficiently manage students, faculty members, departments, courses, and attendance through a centralized platform.
## 🎯 Objectives

- Digitalize academic records
- Simplify student administration
- Reduce manual paperwork
- Improve data accessibility
 
- ## ✨ Features

- Student Management
- Faculty Management
- Department Management
- Course Management
- Attendance Management
- Dashboard
- Secure Login
- CRUD Operations

- ## 🏗 System Architecture

The project follows a three-tier architecture consisting of the presentation layer, business logic layer, and database layer. The frontend communicates with the backend using REST APIs.

## ⚙ Installation

1. Clone the repository.
2. Configure the MySQL database.
3. Update the application.properties file.
4. Run the Spring Boot backend.
5. Start the React frontend.
## 📌 REST APIs

The backend provides REST APIs for:

- Authentication
- Students
- Faculty
- Departments
- Courses
- Attendance
## 🗄 Database

The application uses MySQL to store student records, faculty details, course information, department details, and attendance records.
